## 3 quick tips

Commit messages should say what changed and why, for example Fix login timeout on password reset (JIRA-142). Never “fix stuff”.
Before “Add file” on GitHub, check the breadcrumb at the top. It decides which folder the file lands in.
Every STAR answer ends with a number. You already have them: 50+ hours saved per cycle, and per-test time down from 2h30 to ~1h35.
